# 🛍️ ShopEase - Online Shopping Website

ShopEase is a full-stack e-commerce web application designed to provide users with a simple, modern, and user-friendly online shopping experience.

## ✨ Features

- 🔐 User Registration and Login
- 🏠 Modern Home Page
- 👗 Fashion Products
- 💍 Accessories and Jewellery
- 💄 Beauty Products
- 👟 Branded Footwear
- 🏠 Home Appliances
- 💻 Electronics
- 🔎 Product Details
- 🛒 Shopping Cart
- 💳 Checkout System
- 📦 Order Placement
- 📋 My Orders
- 💰 Indian ₹ Pricing
- 🎨 Responsive and Animated UI
- 🤖 Personalized ShopEase AI Greeting

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- MongoDB Atlas

### Tools
- Visual Studio Code
- Git
- GitHub
